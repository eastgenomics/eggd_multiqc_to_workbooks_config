# eggd_multiqc_to_workbooks_config

A repository for holding config files for use in eggd_multiqc_to_workbooks. These config files set the cells in the excel files to add QC values to.

Present in this repository:
- MYE_config/uranus_qc_workbook_config_v2.0.0.json - Compatible with new capture and include multiqc file names
- MYE_config/uranus_v2.5_qc_workbooks_config_v1.0.0.json - this is the first created file compatible with the old capture
- MYE_config/new_workbook_format_drafts/uranus_v3.0_qc_workbooks_config_v1.0.0.json - compatible with the old capture and new workbook format
